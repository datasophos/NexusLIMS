NexusLIMS now uses a persistent file (`~/.config/nexuslims/config.toml` or `/etc/nexuslims/config.toml`) to configure the application's behavior, independent of the working directory. The prior `.env` style configuration is no longer supported, and requires an upgrade action to the new format:

**Upgrade action:** As of this version, NexusLIMS no longer automatically reads `.env` from the working directory.
To migrate an existing `.env`, run the following from the directory containing the `.env` file, after upgrading to 2.9.0:

```bash
NX_CONFIG_FILE="$PWD/.env" nexuslims config dump --output config-backup.json
env -u NX_CONFIG_FILE nexuslims config load config-backup.json
```

The JSON backup file will contain credentials; you should protect it or remove it after checking the new configuration. The export process requires valid settings and includes any environment variable overrides active when running. See the [configuration guide](../user_guide/configuration.md) for details.
