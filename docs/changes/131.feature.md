NexusLIMS now uses `~/.config/nexuslims/config.toml` by default, independent of the working directory. Configuration commands display the selected file, including when validation fails.

**Upgrade action:** NexusLIMS no longer automatically reads `.env` from the working directory. To migrate an existing `.env`, run the following from its directory:

```bash
umask 077
NX_CONFIG_FILE="$PWD/.env" nexuslims config dump --output config-backup.json
env -u NX_CONFIG_FILE nexuslims config load config-backup.json
```

The JSON backup contains credentials; protect it or remove it after checking the new configuration. The export requires valid settings and includes any process environment overrides. Alternatively, set `NX_CONFIG_FILE` to the absolute path of the existing `.env` for each NexusLIMS process, including services and scheduled jobs. See the [configuration guide](../user_guide/configuration.md) for details.
